Cadence Desktop — 字幕处理管线

本应用的字幕系统采用双通道设计：

  • 通道 A（本地解析）：直接解析 SRT/ASS 文件，不依赖 AI，适用于已有翻译的常规字幕文件
  • 通道 B（AI 处理）：将字幕发送至 DeepSeek API，获得双语翻译 + 样式 + 非对话过滤，生成更高质量的字幕

两个通道最终都产出 Caption[] 数组，统一交给 UI 层渲染。

1. 核心数据类型

Caption（字幕条目）

// src/lib/subtitles.ts export interface Caption { time: string; // 显示时间 "MM:SS" start: number; // 起始时间（秒） end: number; // 结束时间（秒） text: string; // 当前字幕文本（可能含 <i><b> 标签） translation: string; // 翻译文本 }

SubtitleInputEntry（AI 预处理中间格式）

// src/lib/ai-subtitle.ts export interface SubtitleInputEntry { index: number; // 序号（从 1 开始） timestamp: string; // "00:01:23.45 --> 00:01:25.67" text: string; // 剥离了 ASS {} 标签的纯文本 preTranslation?: string; // ASS 中已有的翻译（\N 分隔的第二部分） }

AI JSON 响应格式

// src-tauri/prompts/subtitle-processor.md { "f": "srt", // 格式: "srt" | "ass" "e": [ // 条目数组 { "i": 1, // index — 与输入序号对应 "s": "Hello World", // source — 剥离 HTML 标签的纯原文 "t": "你好世界", // translation — AI 翻译结果 "sh": true, // show — 是否显示（非对话→false） "st": "i" // style — 可选，"i"|"b"|"u" } ] }

2. 完整处理流程

SRT / ASS文件 → readTextFile → processSubtitle → preprocessSubtitleEntries → AI (DeepSeek) → parseAIResponse → parseSubtitleJSON → normalizeCaptionLanguages → Caption[] → setCaptions() → CaptionsDisplay

AI
AI 处理任务（由 prompt 定义）
1. 翻译：中文 → 英文 / 英文 → 中文（自动检测源语言）
2. 非对话检测（sh=false）：方括号 [sound]、括号 (note)、《书名号》、屏幕覆盖文字
3. 样式保留：<i><b><u> 提取到 st 字段，从 s 中移除标签
4. 返回值：严格 JSON，e 数组长度必须等于输入行数

4. 运行时：字幕同步和渲染

时间同步（useCaptionSync）

VideoPlayer.onTimeUpdate → currentTime → handleTimeUpdate() → 查找 Caption → setActiveCaption(index)

每当视频播放时间更新，useCaptionSync 遍历 captions 数组， 找到 currentTime ∈ [caption.start, caption.end) 的字幕条目， 更新 Zustand store 中的 activeCaption 索引，并派生出 activeDisplay = { primary, secondary }（根据 swapSubtitles 开关决定主副语言排列）。

视频上字幕渲染（CaptionsDisplay）

activeDisplay → sanitizeSubtitleHtml() → wrapSubtitleWords() → dangerouslySetInnerHTML → DOM渲染
1
sanitizeSubtitleHtml(text) → string
函数 src/lib/html-sanitize.ts:1
先转义所有 HTML 特殊字符（< > &），再仅解转 <i><b><u> 三个白名单标签，防止 XSS。
2
wrapSubtitleWords(sanitizedHtml, isFavorited?) → string
函数 src/lib/wrap-subtitle-words.ts:1
用正则匹配每个英文单词，包裹为 <span class="sub-word">。
已收藏单词标记 class="sub-word sub-word--fav"。
保留 HTML 实体和标签原样。
点击翻译： CaptionsDisplay 和 SidebarSubtitleTab 都通过 onClick 捕获 .sub-word span 的点击事件，触发 useWordTranslate hook 弹出查词面板。

字幕遮罩（SubtitleMask）

当播放器启用 字幕遮罩 时，SubtitleMask 组件会在视频上叠加一个可拖拽、可缩放的黑色矩形， 用于遮挡硬编码字幕（hard-subbed）。在全屏模式下，遮罩内会显示当前活动字幕的文本， 使用 sanitizeSubtitleHtml() 安全渲染。

遮罩位置以视频容器百分比存储于 playerStore.subtitleMaskRect Zustand state 中。

字幕导航（useCaptionNavigation）

键盘/手柄 触发 → getPrev/NextCaptionIndex() → setPendingNavigation(true) → setActiveCaption(index) → seek → caption.start

当用户按上下键或点击侧边栏条目时，getPreviousCaptionIndex / getNextCaptionIndex 返回目标索引。设置 pendingNavigation = true 后执行 seek，等播放器到达目标时间， useCaptionSync 检测到稳定后清除 pending 标记，恢复正常的 time-driven 同步。

7. 输入输出格式速查

输入：SRT 文件

1 00:00:01,000 --> 00:00:03,500 <i>Hello World</i>\N你好世界 2 00:00:04,000 --> 00:00:06,000 [phone buzzing]

\N = 双语分隔符（AI 输出格式）
[] = 非对话音效

输入：ASS 文件

Dialogue: 0,0:00:01.00,0:00:03.50,Default,,0,0,0,,{\i1}Hello\N你好 Dialogue: 0,0:00:04.00,0:00:06.00,*Default,NTP,0,0,0,,{\an8}麦吉尔先生 ; ↑ 含 \an8 → 预处理跳过

{style tags} = ASS 覆盖标签
\an8 → 非对话屏幕覆盖

中间格式：AI Input

[ { index: 1, timestamp: "00:00:01.00 --> ...", text: "Hello", preTranslation: "你好" }, { index: 2, timestamp: "00:00:04.00 --> ...", text: "[phone buzzing]" } ]

SubtitleInputEntry[]
text = 已剥离 ASS {} 标签

输出：Caption[]

[ { time: "00:01", start: 1.0, end: 3.5, text: "<i>Hello</i>", translation: "你好" }, { time: "00:04", start: 4.0, end: 6.0, text: "[phone buzzing]", translation: "(已过滤...)" } ]

最终格式，直接传递给 UI 组件
text 可能含 <i><b> HTML 标签
