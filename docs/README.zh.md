### 简介

Cadence，意为韵律与节奏。这是一款专为 **听力 + 字幕学习** 设计的桌面视频播放器，精准贴合语言学习者的需求。

### 功能特性

- 🎬 **字幕解析** — 支持 `.srt` / `.ass` 格式，自动识别文件类型；解析双语字幕（原文 + 翻译）
- 🔄 **视频字幕同步** — 播放时自动高亮当前字幕；侧边栏点击时间戳可跳转至对应位置
- 💾 **字幕缓存** — AI 翻译结果通过 SHA-256 哈希自动缓存到本地，重复打开无需重新处理
- 🤖 **AI 智能翻译** — 集成 DeepSeek API，自动翻译单语字幕（中 ↔ 英）
- 🔀 **双字幕合并** — 支持合并两个独立的字幕文件（如每种语言一个文件），按时间戳对齐
- 📝 **大字幕显示** — 视频下方双行双语展示，主次分明
- 🎭 **模糊模式** — 4 级模糊：关闭、模糊第一行、模糊第二行、全模糊；悬停可临时揭示，适合自测
- 🔄 **位置切换** — 一键交换原文和翻译的显示顺序
- 📋 **字幕侧边栏** — 完整的可滚动字幕列表，点击时间戳跳转，自动跟随当前播放位置；宽度可调（280–600px）
- 📖 **单词词典** — 点击字幕中的任意单词，查看 AI 生成的 IPA 音标、词性、中文释义和例句；结果本地缓存
- 🔁 **单句循环** — 循环播放当前字幕句子，专注听力练习；可通过按钮或 `L` 键切换
- 🎭 **字幕遮罩** — 可拖拽调整大小的黑色遮罩，遮挡视频中的硬字幕
- 🎵 **音频转码** — 自动检测不支持的音频编码（DTS、AC3、EAC3、FLAC、OPUS 等），转码为 AAC 192kbps，显示进度条
- ⚡ **播放速度** — 6 档预设：0.5×、0.75×、1×、1.25×、1.5×、2×
- 🎮 **手柄支持** — 完整手柄操控：暂停/播放、快进、音量、侧边栏、遮罩、循环、速度、打开文件、设置
- 🔊 **音量控制** — 垂直音量滑块及静音切换，屏幕音量提示
- 🔄 **自动更新** — 内置更新检查，支持下载进度和一键安装
- ⌨️ **键盘快捷键** — 暂停/播放、字幕跳转、播放速度、音量、全屏、静音、循环、侧边栏、模糊模式、字幕遮罩、行序交换
- 📂 **自由加载** — 通过原生文件对话框打开本地视频和字幕文件；记忆上次打开的视频
- 🎨 **暗色界面** — 沉浸式深色主题，专注学习不刺眼
- 🌐 **国际化** — 支持中文和 English 界面

### 环境依赖

需要安装 **ffmpeg**（包含 ffprobe）以支持音频转码和编码检测：

<details>
<summary><b>Windows</b></summary>

```powershell
# 方式一：winget（推荐）
winget install Gyan.FFmpeg

# 方式二：scoop
scoop install ffmpeg

# 方式三：choco
choco install ffmpeg
```

安装后重启终端，或将 `ffmpeg` 添加到系统 `PATH` 环境变量。

</details>

<details>
<summary><b>macOS</b></summary>

```bash
brew install ffmpeg
```

</details>

<details>
<summary><b>Linux</b></summary>

```bash
# Debian / Ubuntu
sudo apt install ffmpeg

# Fedora
sudo dnf install ffmpeg

# Arch
sudo pacman -S ffmpeg
```

</details>

### 使用说明

1. **打开视频** — 点击工具栏的文件夹按钮，选择视频文件（`.mp4` / `.webm` / `.mkv` / `.avi` / `.mov` / `.flv` / `.wmv`）
2. **加载字幕** — 点击字幕按钮，选择 `.srt` 或 `.ass` 文件
3. **AI 翻译** — 若字幕为单语，系统会提示配置 DeepSeek API 密钥以自动翻译
4. **播放控制** — 使用工具栏按钮、键盘快捷键或手柄
5. **显示调整** — 通过字幕设置弹窗切换模糊模式或交换行序
6. **查词** — 点击字幕中的任意单词，查看 AI 释义
7. **遮挡硬字幕** — 开启字幕遮罩，用遮罩框遮挡视频上的硬字幕

### 键盘快捷键

#### 播放控制

| 按键                  | 功能              |
| --------------------- | ----------------- |
| `空格`                | 播放 / 暂停       |
| `←` / `→`             | 上一条 / 下一条字幕 |
| `↑` / `↓`             | 音量加 / 减       |
| `,` / `<` / `.` / `>` | 减慢 / 加速播放   |

#### 功能切换

| 按键 | 功能                |
| ---- | ------------------- |
| `F`  | 全屏                |
| `M`  | 静音                |
| `L`  | 单句循环            |
| `S`  | 侧边栏              |
| `B`  | 模糊模式（循环 4 级） |
| `R`  | 字幕遮罩            |
| `T`  | 交换字幕行序        |

> 当焦点在输入框时，字母快捷键不生效。方向键和空格始终可用。
